# Day7 starter - 채용공고 필터 (260728)

어제(Day6) 정리한 표에 필터 손잡이 3개(지역 · 경력 조건 · 채널)를 다는 실습입니다.
코드는 이 폴더 안에 전부 있습니다 - 문서에 옮겨 적힌 코드는 없습니다. 실물 파일을 직접 여세요.

## 실행법 (VS Code + Live Server)

1. VS Code에서 이 `starter` 폴더 전체를 엽니다 (`A_완성본`이나 `B_골격` 폴더 하나만 열어도 됩니다).
2. Live Server 확장이 설치되어 있는지 확인합니다. 없다면 확장 탭에서 "Live Server" 검색 후 설치합니다.
3. 실행하고 싶은 `index.html` 파일을 우클릭하고 "Open with Live Server"를 선택합니다. (또는 파일을 열어둔 상태에서 VS Code 하단 상태바의 "Go Live"를 클릭합니다)
4. 브라우저가 자동으로 열리고 표가 뜹니다. select에서 값을 바꾸면 표와 행 수가 바뀝니다.

바꾼 내용이 화면에 반영되지 않으면 브라우저에서 강력 새로고침(Cmd+Shift+R 또는 Ctrl+Shift+R)을 먼저 시도하세요.

`index.html`을 더블클릭해서 파일 탐색기로 직접 여는 방식(`file://`)은 동작하지 않습니다. 반드시 Live Server를 거쳐야 합니다 - 브라우저가 로컬 CSV 파일을 직접 읽는 것을 막기 때문입니다.

## 폴더 구조

```
starter/
  A_완성본/                       기본 코스용 - 완성된 정답 코드
    index.html
    app.js
    data/
      jobs_dirty_A.csv            제공용 원본 데이터 (78행)
      jobs_dirty_A_backup.csv     원본이 깨졌을 때 되돌리는 보험용 사본
  B_골격/                         표준 코스 / 도전 코스용 - 필터 함수 일부가 빈 골격
    index.html
    app.js                        지역 필터만 완성, 직종·채널은 TODO
    data/
      jobs_dirty_B.csv            A와 같은 연습용 원본 데이터 (78행, 정리 후 73행)
  프롬프트_템플릿.md               B_골격의 TODO를 AI에게 채워달라고 요청할 때 쓰는 문장
  README.md                       이 파일
```

## 코스별 시작점

**기본 코스** - `A_완성본` 폴더를 Live Server로 엽니다. 지역 · 경력 조건(category) · 채널 select 값을 하나씩 바꿔보고, "필터 전 N행 -> 지금 M행" 숫자가 바뀌는 장면을 캡처합니다. 코드를 열어보거나 고칠 필요는 없습니다.

**표준 코스** - `B_골격` 폴더를 Live Server로 엽니다. 지역 필터는 이미 동작합니다. `프롬프트_템플릿.md`에서 대상 열을 `category`로 채운 뒤 AI 채팅에 붙여넣어 `app.js`의 `filterByCategory` 함수를 완성합니다. 비교는 기존 `matchesFilterValue`를 사용합니다. 완성되면 저장하고 브라우저를 새로고침해서 경력 조건 필터가 동작하는지 확인합니다. 같은 방식으로 `filterBySource`(채널)까지 완성하면 도전 코스로 넘어갈 수 있습니다.

**도전 코스** - `B_골격`에서 시작해 경력 조건 · 채널 필터를 모두 스스로 완성하고, 초기화 버튼이 원래 행 수로 정확히 돌아오는지 확인합니다. 여력이 있으면 지역과 경력 조건처럼 두 필터를 동시에 걸었을 때 행 수가 어떻게 줄어드는지도 관찰합니다.

## 원본 불변 원칙

- 화면의 표는 CSV 파일을 읽어 메모리 안에서 만든 복사본입니다. 어떤 select를 누르거나 초기화 버튼을 눌러도 `data/` 폴더 안의 원본 CSV 파일 자체는 절대 바뀌지 않습니다.
- 정리(중복 제거 · 원본 빈값 보존)와 필터는 항상 새 배열을 만들어서 반환하는 방식으로 짜여 있습니다 - 원본 배열이나 원본 값을 직접 고치는 코드는 없습니다.
- `A_완성본`에만 있는 `jobs_dirty_A_backup.csv`는 혹시 실습 중 원본 파일 내용을 실수로 지웠을 때 되돌리는 보험용 사본입니다. 평소에는 쓸 일이 없습니다.
