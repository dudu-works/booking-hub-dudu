# AI 부탁 문장 틀 - 필터 함수 완성용 (표준·도전 코스)

이 템플릿은 `B_골격/app.js`의 TODO 함수 2개(`filterByCategory`, `filterBySource`)를
AI 채팅(ChatGPT, Claude 등)에게 채워달라고 요청할 때 그대로 복사해서 쓰는 문장입니다.

빈칸 2개만 채우고, 아래 문장 전체를 AI 채팅창에 붙여넣으세요.

---

## 템플릿 (복사해서 사용)

```
아래 JavaScript 파일의 함수 하나만 완성해줘. 나머지 코드는 절대 건드리지 마.

파일: app.js
완성할 함수 이름: [filterByCategory 또는 filterBySource]
함수 규칙:
- 매개변수는 (rows, value) 두 개다.
- rows는 공고 객체 배열이고, 각 객체는 id, source, title, company, region, category, date 필드를 가진다.
- value가 빈 문자열이면("전체" 선택) rows를 그대로 반환한다.
- value가 비어 있지 않으면 `matchesFilterValue(row.[필터 대상 열], value)`가 참인 행만
  `filter()`로 남긴 새 배열을 반환한다.
- `matchesFilterValue`는 이미 app.js에 있으며, 일반 값의 완전일치와
  `미기재(원본 빈칸)` 선택을 모두 처리한다. 이 helper는 고치지 않는다.
- 원본 rows 배열은 절대 변형하지 않는다(push, splice, sort 금지). filter()로 새 배열만 반환한다.
- 바로 위에 있는 filterByRegion 함수와 구조를 똑같이 맞춘다.

함수 하나만 바꾸고 나머지 코드는 건드리지 마라.
```

---

## 빈칸 채우는 법

| 빈칸 | 뜻 | 채울 값 |
|---|---|---|
| [필터 대상 열] | 어떤 열을 필터링할 함수인지 | `category` (경력 조건용) 또는 `source` (채널용) |
| 비교 방식 | 열 값과 선택값을 비교하는 법 | 기존 `matchesFilterValue` 사용 |

- 경력 조건 필터를 만들 때: 함수 이름 `filterByCategory`, 대상 열 `category`
- 채널 필터를 만들 때: 함수 이름 `filterBySource`, 대상 열 `source`
- 일반 값은 완전일치이며, `미기재(원본 빈칸)`만 기존 helper가 원본 빈칸과 연결합니다. 이번 시간에는 부분일치를 만들지 않습니다.

## 지켜야 할 것

- **함수 하나만 바꾸고 나머지 코드는 건드리지 마세요.** AI가 다른 함수까지 고치려 하면 "그 함수만" 다시 요청하세요.
- AI가 준 코드를 `app.js`의 해당 TODO 함수 자리에 그대로 붙여넣으세요. 함수 이름과 매개변수 이름(`rows`, `value`)은 바꾸지 마세요 - 다른 함수들이 이 이름으로 호출하고 있습니다.
- 코드는 반드시 저장소 파일(`app.js`)에 직접 붙여넣으세요. 문서에서 코드를 드래그 복사하지 마세요 - 보이지 않는 문자가 섞여 들어가 오류가 날 수 있습니다.

## AI 출력이 이상할 때

AI 잘못도 여러분 잘못도 아닙니다 - 빈칸만 다시 채워서 한 번 더 요청하세요. 두 번 해도 안 되면 A_완성본의 같은 함수(`filterByRegion`)를 참고해서 직접 열 이름만 바꿔 써보세요.
